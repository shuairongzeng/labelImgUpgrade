# labelImg项目管理系统设计总结

## 系统概述

为labelImg图像标注工具设计并实现了完整的项目管理系统，实现了项目级别的配置隔离和资源管理。系统采用渐进式集成策略，确保与现有功能完全兼容。

## 🏗️ 核心架构

### 1. 项目数据结构
```
projects/
├── projects_index.json        # 项目索引
├── shared/                    # 共享资源
│   └── models/               # 共享模型文件
├── default/                  # 默认项目
│   ├── project.json         # 项目元数据
│   ├── configs/             # 项目配置
│   │   ├── class_config.yaml
│   │   ├── training_preferences.json
│   │   ├── training_history.json
│   │   ├── ui_preferences.json
│   │   ├── shortcuts.json
│   │   └── ai_settings.json
│   ├── data/                # 项目数据
│   ├── models/              # 项目专用模型
│   ├── exports/             # 导出文件
│   └── runs/                # 训练记录
└── [user_projects]/         # 用户项目...
```

### 2. 核心组件

#### ProjectManager (`libs/project_manager.py`)
- **功能**: 项目的创建、删除、切换和配置管理
- **特点**: 完整的项目生命周期管理
- **API**: 提供统一的项目操作接口

#### ProjectConfigAdapter (`libs/project_config_adapter.py`)
- **功能**: 新旧配置系统的兼容性桥接
- **特点**: 无缝迁移，现有代码零修改
- **API**: 与原有配置接口完全兼容

#### ProjectManagementDialog (`libs/project_management_dialog.py`)
- **功能**: 图形化项目管理界面
- **特点**: 直观的项目创建、编辑、删除操作
- **组件**: 项目列表、详情面板、操作按钮

#### ProjectSelector (`libs/project_selector.py`)
- **功能**: 快速项目切换组件
- **特点**: 集成到主界面工具栏和状态栏
- **类型**: 标准选择器和紧凑型选择器

#### ProjectIntegrationHelper (`libs/project_integration_helper.py`)
- **功能**: 系统集成和迁移工具
- **特点**: 自动配置迁移和系统初始化
- **工具**: 导出/导入、模板创建、清理

## 🔧 集成方案

### 主程序集成点

1. **初始化阶段**
```python
from libs.project_integration_helper import initialize_project_system
initialize_project_system()  # 在main()函数开始时调用
```

2. **主界面工具栏**
```python
from libs.project_selector import ProjectSelector
self.project_selector = ProjectSelector()
self.toolBar.addWidget(self.project_selector)
```

3. **菜单栏集成**
```python
project_menu = self.menubar.addMenu('项目(&P)')
# 添加项目管理相关菜单项
```

4. **配置系统适配**
```python
from libs.project_config_adapter import get_config_adapter
adapter = get_config_adapter()
# 使用adapter替代直接文件操作
```

### 现有组件适配

所有配置相关的操作都通过`ProjectConfigAdapter`进行，确保：
- 类别管理使用项目级配置
- 训练功能使用项目路径
- AI助手使用项目设置
- 数据存储按项目隔离
